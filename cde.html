Padrão de codificação

Define como os arquivos são nomeados e o que o sistema aceita ao receber. O padrão do Grupo vale para todas as empresas; uma Empresa pode ter o seu, que prevalece.

Testar um código

Digite um código real de prancha. A verificação é imediata, campo a campo — use antes de salvar para não recusar arquivo bom no primeiro dia.

Campos do código

Na ordem em que aparecem. Mapeia para é o que permite ao sistema saber qual pedaço é a disciplina e qual é a revisão — mesmo que sua empresa chame o campo de outro nome.
